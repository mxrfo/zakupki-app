# Закупки — локальное приложение Битрикс24

Локальное веб-приложение «АЛЬТЕРНАТИВА · Закупки» для управления закупками внутри Битрикс24. Работает поверх REST API Битрикс24 через BXJS24 (`//api.bitrix24.com/api/v1/`) и использует CRM-сущности (universal items), чат-бота уведомлений (imbot.v2) и локальный кэш метаданных.

## Возможности

- **Мои запросы / Входящие (Действия) / Все закупки** — вкладки со списком заявок на закупку.
- **Роли и права доступа** — сотрудник, руководитель отдела, ответственные; поддержка симуляции роли руководителя и тестового режима.
- **Карточки закупок** — создание и редактирование заявок: товары, суммы, доставка, сроки оплаты/закупа, файлы (счёт), комментарии, делегирование.
- **Уведомления через чат-бота** — бот «Закупки · Приложение» пишет в личные сообщения и групповой чат «Закупки · Уведомления».
- **Проверка орфографии** — русский словарь Hunspell (nspell + dictionary-ru), собирается отдельным файлом для ускорения загрузки.
- **Транслитерация** — кириллица → латиница (cyrillic-to-translit-js) для формирования идентификаторов/ссылок.
- **Кэширование метаданных** — справочники и настройки кэшируются в `localStorage` (ключ `purchase_app_meta_cache_1088`).
- **Drag & drop интерфейс** и модальные окна форм.

## Технологии

- Vanilla JavaScript (без фреймворка), HTML, CSS
- BXJS24 — SDK локальных приложений Битрикс24
- REST API: `crm.item.*`, `user.get`, `imbot.*` и др.
- Сборка: Node.js + esbuild + archiver
- Линтинг: ESLint, Stylelint

## Установка и запуск

```bash
npm install
```

### Разработка

```bash
npm run watch    # пересборка при изменениях в src/ (nodemon)
npm run build    # разовая сборка
```

Результат сборки складывается в `dist/`:

- `dist/index.html` — собранный файл приложения (JS склеивается в порядке, заданном в `scripts/build.js`)
- `dist/spellchecker.js` — отдельно собранный русский словарь Hunspell
- `dist/releases/app_<timestamp>.zip` — архив для загрузки в Битрикс24

### Линтинг

```bash
npm run lint:js    # ESLint по src/**/*.js
npm run lint:css   # Stylelint по src/**/*.css
```

## Развёртывание в Битрикс24

1. Выполните `npm run build`.
2. Создайте локальное приложение в разделе «Разработчикам → Другое → Локальные приложения» (или загрузите ZIP-архив из `dist/releases/`).
3. Выдайте приложению права на необходимые методы REST API (CRM, пользователи, imbot).
4. В `src/js/core/config.js` при необходимости скорректируйте константы окружения: `ENTITY_TYPE_ID`, `currentCategoryId`, `systemUserId`, маппинг полей `DEFAULT_MAPPING`.
5. `APP_BUILD_ID` автоматически подставляется сборщиком при каждом билде.

## Конфигурация окружения

Основные константы находятся в `src/js/core/config.js`:

| Параметр | Назначение |
|---|---|
| `ENTITY_TYPE_ID` | ID типа элементов CRM («Закупки») |
| `currentCategoryId` | ID раздела smart-процесса |
| `systemUserId` | Пользователь, от имени которого выполняются системные действия |
| `DEFAULT_MAPPING` | Соответствие логических полей полям `ufCrm*` |
| `CACHE_KEY` | Ключ localStorage для кэша метаданных |
