# Закупки — локальное приложение для Битрикс24

Single-page приложение для управления закупками внутри портала Битрикс24 (облако, тариф «Профессиональный»).
Работает как статичное локальное приложение: весь интерфейс и логика — в одном `index.html`,
собранным из модулей. Авторизация — через OAuth-сессию портала (BX24 SDK), без хардкода токенов.

## Возможности

- Запросы на закупку со стадиями smart-процесса и ролевой моделью (сотрудник / менеджер / экономист / руководитель / админ).
- Гарантированные уведомления в мессенджер через собственного **чат-бота** (`imbot.v2`, режим `fetch`, без публичного сервера) — сотрудник видит сообщение даже если диалог ранее не существовал.
- Детализация закупок таблицей, расчёт сумм, загрузка входящих счетов, отложки по датам.
- Панель логов, тестовые сценарии и режим «просмотр под ролью» для администратора.

│   │   ├── utils.js      # вспомогательные функции (логирование, toast, форматирование)
│   │   └── init.js       # инициализация, загрузка метаданных, кэш, автообновление

│   │   └── cache.js      # кэш метаданных в localStorage

│   │   ├── render.js     # отрисовка карточек/таблиц, сортировка, вкладки
